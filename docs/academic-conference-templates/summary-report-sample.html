02 执行摘要 / 核心结论 Executive Summary 必要

  1. 叙事转向"效率"。社区从"大力出奇迹"明确转向"用更少算力做同等 / 更大模型"——MoE 卸载、低比特量化、推测解码是三大抓手，多篇 oral 给出 2× 以上吞吐或 −40% 显存的硬数据。
  2. 对齐正在"工程化、去参考模型化"。DPO 系方法普遍去掉 SFT 参考模型，显存减半、门槛降低，对齐从"研究"变成可复用的"工程组件"。
  3. 多模态统一架构收敛。单一 Transformer 处理任意模态的路线压倒了专用编解码器，是中期架构赌注的方向。
  4. 对我们的机会：MoE 卸载 + 无参考偏好优化若落地，可直接压低我们大模型训练 / 对齐成本——这是可量化的硬收益。
  5. 风险 / 缺口：我们在 MoE 基础设施与统一多模态两条线上能力偏薄，存在被拉开 6–12 个月的风险。

03 研究主题全景 Theme Landscape 必要

主题地图（what）——哪些方向在涨 / 在退，代表论文见第 4 节。

▲ 涨高效训练 / MoE专家卸载、低比特量化、推测解码三路并进，目标都是降训练 / 推理边际成本。
▲ 涨对齐 / 偏好优化"去 reference model"成新基线；自博弈 / 在线 DPO 方法激增。
▲ 涨统一多模态架构单一 Transformer 统一任意模态的路线压倒专用编解码器。
— 平Agents / 工具使用仍是热点但增量放缓，集中在 benchmark 与评测而非新架构。
▼ 退纯 scaling law 实证"堆参数"类工作明显减少，让位于效率与方法创新。

04 重点论文精选 Highlighted Papers 必要

从全会议精选 5 篇必读（含 best paper）。完整清单见附录。

Best Paper

Sparse Routing at Trillion Scale: Memory-Efficient MoE via Expert Offloading

MIT · DeepMind · 清华
问题万亿参数 MoE 显存墙
方法按路由热度的分层专家卸载 + 路由预取
结果1.8T on 256×A100，吞吐 2.3×、显存 −41%
为什么重要：把"训得起万亿模型"的门槛显著下移，直接关系我们的训练成本。详见日报 Day 2。
Spotlight

Self-Play Preference Optimization without a Reference Model

Stanford · Anthropic
问题DPO 需 SFT 参考模型，显存翻倍
方法自博弈生成对比对 + 无参考长度归一损失
结果MT-Bench +0.31、显存 −48%、训练 1.4×
为什么重要：可直接简化我们的对齐 pipeline，省掉一份参考模型副本。
Oral

QMoE-Lite: 2-bit 量化下保持推理质量的鲁棒校准

ETH Zürich · Meta FAIR
问题2-bit 量化质量崩塌
方法分层敏感度感知校准 + outlier 混合精度
结果70B 在 2-bit 下质量损失 <1pt
为什么重要：边缘 / 低成本推理场景可用；可与我们的 INT8 方案 AB。
Oral

One Transformer for All Modalities: Joint Token Routing

UC Berkeley · Microsoft Research
问题多模态需多套编解码器
方法跨模态联合 token 路由，单一主干
结果文 / 图 / 音 / 视频统一，6 项基准 SOTA 中 5 项
为什么重要：代表多模态统一架构的收敛方向，是中期架构赌注。
D&B

RealBench: A Reproducibility-Oriented Benchmark for Efficient Training

Mila · Hugging Face
问题效率方法难公平对比
方法统一硬件 / 预算下的标准化评测协议
结果复评 32 个效率方法，1/3 复现不到原报告
为什么重要：我们评估外部效率方案时应以此为对照基准。

05 关键趋势与信号 Trends & Signals 推荐

Benchmark 格局：效率类工作开始被 RealBench 这类"可复现基准"统一口径，约 1/3 过去的效率声明无法复现——意味着我们引用外部效率数据时要打折扣，优先自测。

SOTA 推进：万亿 MoE 训练、2-bit 推理、无参考对齐三项的 SOTA 都被本次会议明显推高；统一多模态架构在 6 项基准中拿下 5 项 SOTA。

资源 / 数据集：Datasets & Benchmarks 轨继续升温，尤其"可复现性"与"评测协议"类数据集；代码开源率仍高（重点论文 5/5 开源）。

冒头子方向：推测解码与 MoE 的结合、在线 / 自博弈 DPO、跨模态联合路由——三者明年大概率成为独立子赛道。

06 对我们的启示与建议 Implications 必要

要投的方向MoE 基础设施与统一多模态架构——两者都是中期胜负手，我们目前能力偏薄，建议立项。
可落地的方法无参考偏好优化（省一份参考模型副本）与2-bit 推理量化（低成本 / 边缘场景）——工程门槛低、收益可量化，优先接入。
能力差距MoE 训练栈、跨模态联合路由缺乏积累，存在被拉开 6–12 个月的风险；评测侧缺自有可复现基准。
风险外部效率声明约 1/3 不可复现，决策前一律自测；统一架构路线若成主流，专用多模态栈有被淘汰风险。
招聘 / 合作重点关注 MoE 系统、推测解码、对齐工程方向的人 / 实验室（MIT、Stanford、Berkeley、ETH）；今年现场这类人才抢手、开价偏高。
